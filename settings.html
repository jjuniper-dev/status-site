ℹ️ About Settings

This settings page provides secure, local management of your API keys, MCP servers, model memory, and custom skills. All data is encrypted using your browser's Web Crypto API and stored in local storage—nothing is sent to external servers.

Privacy: Your configuration is only stored on this device. Clear browser data to delete all settings.

Backup: Periodically export your settings to keep a secure backup.
