# AI Platform Intelligence

## Core Position
HC/PHAC requires a defensible enterprise AI operating model spanning control plane, runtime, and data governance.

## Capability Landscape

### PATH
- Status: Pre-prototype
- Role: Target-state control plane
- Risk: Must not be presented as an operational platform

### HAIL
- Status: Operational runtime
- Stack: Azure Databricks + Unity Catalog
- Gap: ATO, telemetry, and ownership model remain unresolved

### Copilot-Class
- Role: Workforce productivity enablement
- Risk: Convenience can outpace governance controls

## Key Insights
- Runtime deployment is not equivalent to governance maturity
- Enterprise control-plane capability remains the primary gap
- PATH and HAIL cannot stay conceptually or operationally fragmented

## Recommendations
- Define PATH/HAIL convergence architecture
- Establish inherited control baseline across AI workloads
- Clarify AI-Ops ownership and support model

## Risks
- Shadow AI expansion through sanctioned tools
- HAIL production exposure if ATO path lags
- Fragmented decision narratives across EA, CDO, and delivery
