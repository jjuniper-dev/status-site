# Artifact Inbox

Drop any file here (image, slide, PDF, etc.).

The GitHub Action will:
- detect new files
- generate metadata
- create a detail page
- update the artifacts index

Naming tip:
Use descriptive filenames like:

enterprise-automation-model-agents-bpa-rpa-hitl.jpeg

This becomes the artifact title and slug.

After upload:
- wait ~30–60 seconds
- check /artifacts.html

You can later refine metadata directly in data/artifacts-index.json
