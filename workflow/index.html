AI Development Lifecycle

Cost-optimized orchestration of AI agents for non-developer workflows

Tier 1 — Fast / Cheap

Tools: ChatGPT (default), Claude Haiku

Use:

  • Specs
  • JSON schemas
  • Simple code
  • Debugging

Tier 2 — Builder

Tools: Claude Sonnet

Use:

  • Multi-file logic
  • Refactoring
  • Architecture shaping

Tier 3 — Execution

Tools: Claude Code, Codex

Use:

  • Write real files
  • Edit repo
  • Implement features

Tier 4 — Deep Reasoning

Tools: Claude Opus

Use:

  • Complex decisions
  • Architecture validation
  • Edge cases

Cost Control Logic

Rule: Always use the lowest capable model first.

Is task simple? → ChatGPT Is it structural? → Claude Sonnet Does it require real code changes? → Claude Code / Codex Am I stuck or high-risk? → Claude Opus
