Rubric Interpretation
High-level reading guide for how this comparison frame should be used.

Gates first. A vendor that fails core gates cannot be treated as enterprise-viable even if model capability is high.

Composite scores help rank options, not approve them. Approval still depends on governance pathway, architecture fit, and deployment context.

Architecture fit matters. The best model is the one that can be safely integrated into the control plane and supported operationally.

Use this page as decision support. It should inform ARB, options analysis, and intake reviews rather than replace them.
